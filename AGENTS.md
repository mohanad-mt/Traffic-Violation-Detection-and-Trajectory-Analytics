# Traffic project workflow

Start technical work by reviewing the relevant literature and available open-source implementations. Read the papers and inspect the code that implements the candidate methods. Compare their assumptions, data, and computational cost with our footage before choosing an approach. Record the sources and the reason for the choice in the experiment notes.

Start from a reproducible baseline, change one factor at a time where practical, and record the clips, configuration, metrics, and failures. Choose settings on development data and validate on separate cameras when available. Report vehicle detection, tracking, and alert results at their respective levels.

Keep changes reviewable on a feature branch. Update the reproduction instructions and run the relevant tests before publishing.
